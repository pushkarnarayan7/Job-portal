# Deployment Guide

This app deploys in three parts:

| Part | Platform | Free tier |
|---|---|---|
| Database | MongoDB Atlas | Yes (M0) |
| Backend (Express API) | Render | Yes |
| Frontend (React/Vite) | Vercel | Yes |

Deploy in this order: **Database → Backend → Frontend** (the frontend needs the backend URL, and the backend needs the frontend URL for CORS).

---

## 0. Push to GitHub

Both Render and Vercel deploy from a Git repo. From the `Job_Portal` folder:

```bash
git init
git add .
git commit -m "Job portal ready for deploy"
git branch -M main
git remote add origin https://github.com/<you>/<repo>.git
git push -u origin main
```

> A `.gitignore` is included so `node_modules`, `dist`, and `.env` files are not committed.

---

## 1. MongoDB Atlas (database)

1. Create a free account at https://www.mongodb.com/atlas and create an **M0 (free) cluster**.
2. **Database Access** → add a database user (username + password). Save the password.
3. **Network Access** → Add IP `0.0.0.0/0` (allow from anywhere — needed so Render can connect).
4. **Clusters → Connect → Drivers** → copy the connection string. It looks like:
   ```
   mongodb+srv://<user>:<password>@cluster0.xxxxx.mongodb.net/job_portal?retryWrites=true&w=majority
   ```
   Replace `<user>` / `<password>`, and add `/job_portal` before the `?` as the database name.

Keep this string — it's your `MONGO_URI`.

---

## 2. Render (backend API)

There is a `render.yaml` blueprint at the repo root, so the easiest path is:

1. Go to https://dashboard.render.com → **New → Blueprint** and select your GitHub repo.
2. Render reads `render.yaml` and creates the `job-portal-backend` web service.
3. When prompted, fill in the environment variables it can't auto-generate:
   - `MONGO_URI` → your Atlas connection string from step 1
   - `FRONTEND_URL` → leave a placeholder for now (e.g. `https://example.com`); you'll update it after step 3
   - `JWT_SECRET` → auto-generated by Render (leave as is)
4. Click **Apply**. Wait for the build/deploy to finish.
5. Copy the service URL, e.g. `https://job-portal-backend.onrender.com`.
6. Test it: open `https://job-portal-backend.onrender.com/api/health` — you should see
   `{"success":true,"message":"API is healthy"}`.

### Manual alternative (no blueprint)

New → **Web Service** → pick repo, then set:
- **Root Directory**: `backend`
- **Build Command**: `npm install && npm run build`
- **Start Command**: `npm start`
- **Health Check Path**: `/api/health`
- Add env vars: `MONGO_URI`, `JWT_SECRET`, `FRONTEND_URL`.

> Note: Render's free tier sleeps after inactivity, so the first request after idle can take ~30–50s to wake.

---

## 3. Vercel (frontend)

1. Go to https://vercel.com → **Add New → Project** → import your GitHub repo.
2. Set **Root Directory** to `frontend` (click *Edit* next to the root directory).
3. Vercel auto-detects Vite (`vercel.json` is already included for SPA routing).
4. Add an **Environment Variable**:
   - `VITE_API_BASE_URL` = `https://job-portal-backend.onrender.com/api`
     (your Render URL from step 2, with `/api` appended)
5. Click **Deploy**. Copy the resulting URL, e.g. `https://your-app.vercel.app`.

---

## 4. Connect the two (CORS)

1. Back in Render → your backend service → **Environment** → set:
   - `FRONTEND_URL` = `https://your-app.vercel.app` (your Vercel URL, **no trailing slash**)
2. Save — Render redeploys automatically.

`FRONTEND_URL` accepts a comma-separated list if you want to allow multiple origins, e.g.
`https://your-app.vercel.app,http://localhost:5173`.

---

## 5. Verify

- Open your Vercel URL.
- Register / log in (recruiter: `recruiter@jobportal.com`).
- As recruiter, post a job; as a visitor, browse and view it.
- If API calls fail, check the browser console:
  - **CORS error** → `FRONTEND_URL` on Render doesn't exactly match your Vercel origin.
  - **Network/500** → check Render logs and that `MONGO_URI` is correct and Atlas allows `0.0.0.0/0`.

## Environment variables reference

**Backend (Render)**

| Key | Example |
|---|---|
| `MONGO_URI` | `mongodb+srv://user:pass@cluster0.../job_portal` |
| `JWT_SECRET` | (long random string) |
| `FRONTEND_URL` | `https://your-app.vercel.app` |
| `PORT` | set automatically by Render |

**Frontend (Vercel)**

| Key | Example |
|---|---|
| `VITE_API_BASE_URL` | `https://job-portal-backend.onrender.com/api` |
